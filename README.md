# 🧑‍💻 CV Personnel Interactif — Aymane Hamouch

Un portfolio/CV personnel interactif développé avec **React** et **jQuery**, déployé sur GitHub Pages.

🔗 **Lien du site :** https://aymanehamouch05.github.io/projet-cv/

## 🚀 Technologies utilisées

- React 19
- Vite
- CSS3 (variables, animations, responsive)
- jQuery (accordéon, barres de progression)
- GitHub Pages (déploiement)

## ✨ Fonctionnalités

- 🌙 Mode sombre / clair
- 📸 Lightbox photo de profil
- 📊 Barres de compétences animées
- 🎓 Timeline de formation (accordéon)
- 💼 Section projets
- 📬 Formulaire de contact
- 🎞️ Animation au scroll (Intersection Observer)
- 📱 Responsive (mobile, tablette, desktop)

## 📦 Installation

```bash
git clone https://github.com/aymanehamouch05/aymanehamouch05.github.io.git
cd aymanehamouch05.github.io/projet-cv
npm install
npm run dev
```


## 🚀 Déploiement
